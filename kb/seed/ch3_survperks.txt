CHAPITRE 3
3. Survivant : toutes les perks (tier list)
Cette tier list couvre les 176 perks survivant distinctes du jeu au patch 10.1.2a (54 survivants × 3 perks, plus les perks
générales). Les trois perks de Laurie Strode, devenues générales en janvier 2026 sous d'autres noms, sont comptées une
seule fois (par exemple Will to Live = Decisive Strike).
Comment utiliser cette tier list
Le tier mesure la valeur moyenne d'une perk dans la méta actuelle, pas sa valeur dans un build précis. Une perk C peut
être excellente dans le bon build (Stake Out avec Hyperfocus, Flip-Flop avec Power Struggle). Construisez vos builds par
catégories (chapitre 5) plutôt qu'en prenant « les quatre meilleures ».
Sources du classement : tier lists timesaver.gg (patch 10.1.2, septembre 2026) et playhub.com (juillet 2026), taux
d'utilisation et d'évasion NightLight.gg (septembre 2026), consensus communautaire. En cas de désaccord entre sources, le
choix est expliqué en fin de chapitre.

• Reworks : Borrowed Time (soin passif du Deep Wound), Down to the Last (jetons, bonus pour les portes et la trappe),

Burden (Broken au lieu d'Exposed).
• Buffs chiffrés : Kindred (14/15/16 m), No One Left Behind (80/90/100 %), Resilience (7/8/9 %), We'll Make It (70/80/90
s), Better Than New (40/45/50 %), Empathic Connection (40/45/50 %), Flow State (13/14/15 %), Friendly Competition
(10 % pendant 80/85/90 s), Bound by Obsession (8/9/10 %, sur plus d'actions), Calm Spirit (devient plus rapide :
8/9/10 %), Dark Sense (8/9/10 s + palettes/fenêtres/survivants), This Is Not Happening (zones bien plus grandes),
Solidarity (65/70/75 %), Boon: Illumination, Plunderer's Instinct, Pharmacy, Blood Pact, Wake Up!, Do No Harm.
• Nerfs : Self-Preservation (Elusive 13/14/15 s au lieu de 20/25/30 s).
